# TK Utility仮想通貨システム仕様書 v2.0

## 概要
TKUtilityに実装された仮想通貨システム「TK Economy」の完全仕様です。TKUP（Talk Utility Points）とTKUC（TK Utility Coin）の2つの通貨を基盤とした経済システムを提供します。

## 通貨仕様

### TKUP (Talk Utility Points)
- **獲得方法**: Discordサーバーでのチャット活動
- **獲得レート**:
  - テキストメッセージ: `4 + min(20, 文字数)` TKUP/メッセージ
  - 画像投稿: `8` TKUP/画像
- **獲得上限**: `1,000` TKUP/1時間（Rolling Window）
- **VC参加**: 対象外（テキスト・画像のみ）

### TKUC (TK Utility Coin)
- **変動**: プログラム計算 + 取引価格反映
- **変動範囲**: -10% ～ +10%（最小±0.1%）
- **レート範囲**: 100 TKUP ～ 2,000 TKUP
- **更新間隔**: 1分毎
- **初期レート**: 500 TKUP = 1 TKUC

## 取引仕様

### 即時取引
- **購入**: TKUP → TKUC（手数料5%）
- **出金**: TKUP → 円相当（手数料10%）
- **送金**:
  - TKUP送金: 手数料3%
  - TKUC送金: 手数料なし

### オーダー取引（DEX）
- **買い注文**: 指定価格でTKUC購入予約
- **売り注文**: 指定価格でTKUC売却予約
- **自動マッチング**: 買い価格 ≥ 売り価格で即時約定
- **マッチング優先度**: 買い（価格降順）、売り（価格昇順）

### 月末リセット
- **タイミング**: 毎月1日0時0分
- **処理**: 全ユーザーのTKUP/TKUC残高を0にリセット
- **保持データ**: 獲得履歴（統計用）

## コマンド仕様

### 基本コマンド
| コマンド | 説明 | パラメーター |
|---------|------|-----------|
| `/tk-balance` | 残高表示 | なし |
| `/tk-buy` | TKUC購入 | `<amount>` TKUC数量 |
| `/tk-send-tkup` | TKUP送金 | `<user>` `<amount>` |
| `/tk-send-tkuc` | TKUC送金 | `<user>` `<amount>` |
| `/tk-withdraw` | TKUP出金 | `<amount>` |
| `/tk-gamble` | TKUCギャンブル | `<amount>` ベット額 |

### 市場コマンド
| コマンド | 説明 | パラメーター |
|---------|------|-----------|
| `/tk-market` | 市場情報+チャート | `[points]` データポイント数 |
| `/tk-leaderboard` | ランキング表示 | `<type>` `<limit>` |

### 取引所コマンド
| コマンド | 説明 | パラメーター |
|---------|------|-----------|
| `/tk-buy-order` | 買い注文 | `<price>` `<amount>` |
| `/tk-sell-order` | 売り注文 | `<price>` `<amount>` |
| `/tk-orders` | オーダー板表示 | なし |
| `/tk-cancel-order` | 注文キャンセル | `<order_id>` |



## レート変動アルゴリズム

### 基本変動
```javascript
const changePercent = (Math.random() - 0.5) * 20; // -10% to +10%
const newRate = currentRate * (1 + changePercent / 100);
const clampedRate = Math.max(100, Math.min(2000, newRate));
```

### 取引価格反映
- オーダー取引成立時、約定価格でレート更新

## ランキングシステム
- **TKUPランキング**: 保有量降順
- **TKUCランキング**: 保有量降順
- **表示上限**: 25位まで

## チャート機能
- **サイズ**: 800×400px
- **データ**: 最新50ポイント
- **時間表示**: 日本時間（JST）
- **フォント**: 日本語対応

## スケジューリング
- **レート更新**: 1分毎 (`* * * * *`)
- **月末リセット**: 毎月1日0時 (`0 0 1 * *`)
